# Changelog

## 0.2.0 — 2026-10-02

- `onTrack` option: called once for every event the tracker accepts (from `track()` and
  from plugins), for logging or mirroring events.

## 0.1.0 — 2026-10-01

First release used by momoto-fe.

- Batched and real-time delivery, beacon flush on page hide, reload restore, identity
  and consent, `pageViews` / `autocapture` plugins, React bindings.
